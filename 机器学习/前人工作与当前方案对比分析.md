# 台风预测：前人工作与当前方案对比分析

## 1. 对比范围与当前方案

本文基于已核对的六项相关研究，以及当前[开题报告方案](C:/Users/23292/Desktop/weather/开题报告_第3与第4题.md)整理。这里的“当前方案”指拟开展的研究计划，尚未实施的新模型、环境数据补充和验证结果均采用计划语气。

研究以台风路径预测为主线，台风分类用于特征分析，登陆后风速与降水建模作为扩展。当前思路包括：

1. 整理现有1945—2023年历史台风路径数据，按台风编号和时间构建样本，以过去24小时的状态序列预测未来6、12、24小时的二维位移。
2. 建立保持当前速度和方向的外推模型、SVR模型及LSTM模型，研究注意力机制是否改善转向和速度突变时的表现。
3. 补齐环境资料后，利用CNN提取多层风场、位势高度场等网格特征，与LSTM提取的历史序列特征融合。
4. 按年份与完整台风事件划分数据，在同一测试样本上比较模型；以各预测时效的位置大圆距离误差为主要指标，DTW作为轨迹形状的辅助指标。
5. 开展台风类别与预测误差的分析；取得真实降水资料后，研究距离、方位角、湿度、风切变、地形等变量对登陆后降水建模的作用。

核心判断：**LSTM、CNN、注意力、多源融合和多时效位移预测均已有研究基础。当前方案主要体现为这些方法在现有数据上的应用与验证，以及对本地实验流程的完善；是否具有新的模型贡献，需要后续实验和更全面的文献比较确认。**

## 2. 具体前人工作及其与当前方案的关系

### 2.1 Gao等（2018）：基于LSTM的台风路径临近预报

**论文：** *A nowcasting model for the prediction of typhoon tracks based on a long short term memory neural network*。[1]

该研究利用1949—2011年的台风观测数据训练LSTM，开展6—24小时路径预测，说明历史序列中的时间依赖可以用于路径预报。

与当前方案相同的部分是使用LSTM进行短期路径预测。当前方案拟进一步比较环境特征和注意力模块的贡献，并检查转向、登陆、快速移动等样本的误差。后续环境融合研究对早期仅依靠台风自身历史特征的模型提出了补充环境因素的方向，但不能据此说Gao等没有考虑时序信息。[1][3]

**对比结论：** 将其作为时序模型的直接研究基础；“采用LSTM”是方法借鉴，环境补充及困难样本分析是拟研究方向。

### 2.2 Giffard-Roisin等（2020）：历史路径与再分析环境场融合

**论文：** *Tropical Cyclone Track Forecasting Using Fused Deep Learning From Aligned Reanalysis Data*。[2]

该研究融合历史位移及以台风中心对齐的风场、位势高度场，直接估计未来24小时的经纬度位移。其数据包含两个半球1979年以来超过3000个风暴，并按风暴事件划分训练、验证与测试集合。

当前方案中的“以台风中心裁剪环境场”“融合历史路径与环境资料”“直接预测未来位移”和“避免同一台风跨训练、测试集合”等思路，均与该工作存在明显重合。该研究主要验证24小时预测，作者指出模型需要当前及过去的再分析场，并将其定位为概念验证。[2]

**对比结论：** 当前方案可以扩展为6、12、24小时的统一比较，并研究较新环境资料上的适用性；不能把多源融合或事件划分本身表述为原创。采用ERA5也不能预先保证性能提升。

### 2.3 Liu、Hao、Geng和Shi（2022）：DBF-Net多时效路径预测

**论文：** *Dual-Branched Spatio-temporal Fusion Network for Multi-horizon Tropical Cyclone Track Forecast*。[3]

DBF-Net使用LSTM编码解码分支处理台风自身的历史特征，使用CNN分支处理位势高度场，再融合预测未来6、12、18、24小时路径。论文还比较了外推、统计模型及其他深度学习方法，并开展分支结构的消融实验。

其预印本表4报告24小时平均距离误差为119.05 km，该数值只对应该文的数据和实验设置。作者指出，与SHTP区域数值预报模型仍有精度差距，采用更高分辨率环境资料可能改善表现。[3]

当前方案的“CNN与LSTM双分支融合”“多时效预测”“基线比较”和“消融验证”与DBF-Net高度接近。当前方案计划额外研究注意力机制，但模块的有效性必须在相同数据、划分和预测时效下检验。

**对比结论：** DBF-Net是最接近当前核心思路的参照方法。仅组合CNN和LSTM不足以构成创新；需明确实际融合结构的差异，报告精度与模型复杂度，才能判断是否有所改进。

### 2.4 Chen等（2019）：CNN-LSTM台风生成与强度预测

**论文：** *A hybrid CNN-LSTM model for typhoon formation forecasting*。[4]

该研究使用二维、三维CNN学习大气和海洋变量的空间关系，使用LSTM学习时间关系，服务于台风生成与强度预测。该文出现在本目录原论文的参考文献中。

当前方案借鉴其时空建模思路，但输出目标为未来二维位移，属于不同预测任务。生成、强度与路径预测的标签及评价方式不同，不能直接把该文的性能结论当作路径预测效果的依据。

**对比结论：** 适合作为网络结构的相关研究引用，不宜作为路径预测的直接性能基线。任务应用可以成为课程设计内容，但是否属于学术创新需结合其他路径研究判断。

### 2.5 He等（2023卷期）：双注意力多通道ConvLSTM风速预测

**论文：** *A Dual-Attention-Mechanism Multi-Channel Convolutional LSTM for Short-Term Wind Speed Prediction*。[5]

该研究使用华北部分地区ERA5近地面网格资料，结合通道注意力、空间注意力和ConvLSTM，进行6小时风速预测。该文发表于2023年卷期，在线发表日期为2022年12月30日，也出现在本目录原论文参考文献中。

当前方案拟研究注意力机制对台风路径特征融合的作用，与该研究存在方法上的联系，但区域近地面风速、台风中心最大风速和台风路径位移属于不同目标。

**对比结论：** 注意力机制可借鉴，其对台风路径的贡献需单独验证。设置相同输入、训练条件和测试样本下的“有注意力/无注意力”比较；不能因原文风速预测改善就预先宣称路径预测改善。

### 2.6 Ueno（2007）：风切变与台风降水不对称性

**论文：** *Observational Analysis and Numerical Evaluation of the Effects of Vertical Wind Shear on the Rainfall Asymmetry in the Typhoon Inner-Core Region*。[6]

该研究结合西北太平洋台风的雷达、卫星降水资料和数值试验，分析垂直风切变及台风强度与降水空间不对称性的关系。

它为当前降水扩展方案中加入方位角、风切变、强度等变量提供物理依据。当前方案拟使用真实降水资料比较简单衰减模型和多变量模型，研究目标与该文的机制分析不同。

**对比结论：** 可支撑“仅靠距中心距离难以充分描述降水分布”的论点；它属于观测与机制研究，不是机器学习降水预测基线。它支持补充特征的动机，不保证具体模型一定有效。

## 3. 前人工作与当前方案的逐项对照

| 对比维度 | 前人已有工作 | 当前方案 | 对比分析 |
| --- | --- | --- | --- |
| 历史序列建模 | Gao等已使用LSTM进行6—24小时路径预测 | 使用过去24小时状态序列，比较SVR、LSTM及注意力模型 | 时序建模有直接基础，重点在同一数据下验证各方法 |
| 环境数据融合 | Giffard-Roisin等融合历史位移、风场和位势高度场；DBF-Net融合自身特征与位势高度场 | 补齐风场、位势高度等资料，研究CNN与LSTM融合 | 多源融合是借鉴；环境变量及融合结构的贡献需消融确认 |
| 环境场对齐 | Giffard-Roisin等采用以台风中心为基准的移动参考系 | 按预测起点位置裁剪环境区域 | 属于已有思路的应用，需明确裁剪范围及时间匹配 |
| 未来位置输出 | Giffard-Roisin等直接预测24小时位移；DBF-Net开展多时效路径预测 | 直接预测6、12、24小时二维位移 | 相对本地仅预测速度的部分流程更完整，但非领域首次提出 |
| 注意力机制 | He等在区域风速任务中使用通道、空间注意力；本地论文亦提及通道注意力 | 检验注意力对路径预测的贡献 | 需要实现清晰的模块和受控比较，不能仅以模块名称主张创新 |
| 数据划分 | Giffard-Roisin等已按风暴事件分离训练、验证、测试集合 | 按年份与完整台风事件划分，保证事件不跨集合 | 是合理验证要求；可完善本地实验，非新算法贡献 |
| 评价方式 | DBF-Net报告不同预测时效的距离误差；NHC采用同一验证时刻的大圆距离 | 按时效报告位置大圆距离误差，DTW辅助评价路径形状 | 增强结果的明确性与可比性，不宜把DTW对齐后的相似性等同于准时准确 |
| 消融实验 | DBF-Net已比较分支结构的贡献 | 分别移除环境信息或注意力模块，并比较序列模型 | 是检验改进来源的必要手段，不能将前人概括为没有消融 |
| 台风分类 | 上述核心文献主要研究路径或相关气象任务，不能直接支撑本项目的聚类效果 | 按季节、强度、路径特征等开展分析，考察各类误差 | 属于辅助分析；需明确类别定义，不将聚类结果直接等同于业务等级 |
| 登陆后降水 | Ueno等提供风切变与降水不对称性的观测依据 | 在真实资料上引入距离、方位、湿度、风切变及地形 | 具有物理动机，但需验证预测收益；与路径任务分别训练和评价 |

文献间的指标不宜直接横向排序。只有统一测试台风、预测起点、时效、输入可用性和误差定义，才能进行公平比较。例如，DBF-Net的119.05 km不能直接与本地论文未明确单位的RMSE数值比较。

## 5. 实验比较应如何落地

### 5.1 路径预测的比较组

| 比较组 | 输入和模型 | 用途 |
| --- | --- | --- |
| A | 当前及历史位置构造的速度、方向外推 | 检查复杂模型是否优于简单运动外推 |
| B | 历史路径与强度特征，SVR直接预测二维位移 | 检查非线性回归基线的表现 |
| C | 历史状态序列，LSTM | 检查序列建模的贡献 |
| D | 历史状态序列，LSTM加注意力 | 在C基础上检验注意力的贡献 |
| E | 历史状态序列及网格环境场，CNN与LSTM融合 | 检验环境信息的增益 |
| F | 与E相同的数据，融合模型加注意力 | 在E基础上检验注意力对时空融合的贡献 |

各组统一输出6、12、24小时预测，采用相同事件划分与可用样本。环境场数据缺失时，先完成A至D；E与F的数据补齐后，应在共同样本上重新比较，避免不同样本导致表面增益。各模型使用相近的调参预算，并报告参数量或推理耗时，防止仅增加模型规模却不说明计算代价。

如果实际复现DBF-Net，应按照其公开描述实现并说明与原设置的差异；若只实现一个简化融合网络，应使用“CNN-LSTM融合基线”等名称，避免冒充原模型复现。

### 5.2 数据与指标约束

样本构造只使用预测起点及之前的信息，移动速度和方向由历史位置计算，不利用未来位置补成输入。按年份划分时，跨年份的同一台风整体归入一个集合；标准化和聚类等可学习处理仅在训练资料上拟合。

路径评价以每个时效的预测中心与真实中心的大圆距离为基础，报告平均误差、样本量及必要的误差分布，并按完整台风汇总检查结果是否由少数长轨迹主导。DTW用于补充描述轨迹形状，不能代替同一时刻的位置准确性评价。[7]

使用ERA5开展历史回报实验时，只输入预测起点及之前对应的环境场，不使用未来环境场。即便这样，再分析场仍是事后重建资料，实验结论应限定为历史回报能力；能否用于实时业务，还需使用当时可获得的观测或数值预报资料检验。[2][8]

降水扩展另行构造站点或格点样本，明确预测时段，区分当地风速、中心最大风速、时段降水量和累计降水量。取得真实观测后再报告预测效果，不能以合成数据的拟合误差替代真实事件验证。

## 6. 可直接用于开题报告的总结

### 6.1 前人工作及其局限

已有台风路径预测研究逐步从历史序列建模发展到时空特征融合。Gao等利用LSTM开展6—24小时路径预测，说明历史状态中的时间依赖具有预测价值；Giffard-Roisin等融合历史位移与台风中心对齐的风场、位势高度场，实现24小时位移预测，但研究仍主要属于再分析资料上的概念验证；Liu等提出DBF-Net，通过CNN与LSTM双分支实现多时效路径预测，并开展基线与消融比较，同时指出其与区域数值预报模型仍存在精度差距。因此，不能笼统地认为已有方法缺少时序建模或多源融合，后续研究应关注环境资料的分辨率与可获得性，以及不同预测时效和复杂台风样本下的表现。[1][2][3]

在相关任务中，Chen等的CNN-LSTM台风生成与强度预测、He等的双注意力风速预测，为网络结构设计提供了参考，但其性能结论不能直接迁移到路径预测。对于降水扩展，Ueno等的研究表明环境风切变与台风降水不对称性有关，为增加方位角、风切变和强度等特征提供了依据。因此，真实降水预测需要观测数据支持，并检验多变量模型是否优于简单距离衰减关系。[4][5][6]

### 6.2 当前方案相对前人工作的定位

本研究拟在已有时序建模和时空融合方法基础上，利用现有中国近海台风历史路径资料，构建未来6、12、24小时的二维位移预测任务。首先比较运动外推、SVR与LSTM模型，再在补齐环境资料后研究CNN与LSTM融合，并通过受控消融实验检验注意力机制的贡献。实验按年份和完整台风事件划分，采用各时效的位置大圆距离误差，重点分析转向、登陆和快速移动样本；分类分析用于解释不同类别的误差，真实降水建模作为数据条件允许时的扩展。

当前方案与前人工作共享LSTM、CNN、注意力和环境融合等技术基础，主要价值在于完成统一、可复现的实验比较，并完善本地实验中的预测目标和真实数据验证。是否存在进一步的模型改进，应以相同实验条件下的结果为依据；注意力组合及环境数据补充本身不宜直接表述为原创创新。
