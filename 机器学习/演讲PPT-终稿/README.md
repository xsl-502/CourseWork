## 四、使用说明

### 4.1 现场演示（推荐 PDF 版）

1. **拷贝文件**：将 `演讲PPT.pdf` 拷贝至教室电脑（细则要求"携带备份"）。
2. **播放**：
   - macOS：Preview / Keynote 打开，按 `⌘+Shift+F` 全屏
   - Windows：Adobe Acrobat / Foxit / Edge 打开，按 `F11` 全屏
   - 翻页：空格键 / 方向键
3. **字体无忧**：PDF 已嵌入字体（PingFang SC / Heiti SC / STKaiti），任何平台显示一致。

### 4.2 临时编辑（PPTX 版）

1. **打开**：双击 `演讲PPT.pptx`，用 WPS / PowerPoint / Keynote 打开。
2. **编辑**：
   - 所有文字可直接点击编辑（非图片）
   - 表格、图表、形状均可调整
   - 字体默认：微软雅黑（标题/正文）、楷体（装饰）、Consolas（代码）
3. **保存**：编辑后另存为新文件，避免覆盖原版。

**注意**：PPTX 版字体未嵌入，若教室电脑缺字体会自动替换（通常替换为宋体/黑体，影响不大）。若需保证字体一致，仍推荐 PDF 版。

### 4.3 重新编译 PDF（需 LaTeX 环境）

```bash
cd /Users/xsl/Desktop/CourseLearning/机器学习/演讲PPT-终稿
xelatex 演讲PPT.tex
xelatex 演讲PPT.tex  # 运行两次生成目录
```

**前置条件**：
- 已安装 TeX Live / MacTeX（含 xelatex）
- macOS 系统字体：PingFang SC / Heiti SC / STKaiti（macOS 自带）
- 图表文件完整：`figures/` 和 `pic/` 文件夹

### 4.4 重新生成 PPTX（需 Python 环境）

```bash
cd /Users/xsl/Desktop/CourseLearning/机器学习/演讲PPT-终稿
pip3 install python-pptx  # 首次运行需安装
python3 build_pptx.py
```

生成 `演讲PPT.pptx`（1.3 MB），共 14 页。
