# 开题报告第3、4题建议稿

本文依据本目录中的《台风的分类与预测》（paper.pdf）、历史台风路径数据及 MATLAB 实验代码整理。研究以台风路径预测为核心，台风分类用于特征分析，登陆后风速与降水建模作为扩展。以下采用开题报告的计划语气，不将尚未完成的改进写成已取得的实验结论。

## 3. 前人工作存在的问题

**（1）部分统计模型对台风时序变化及环境因素的联合刻画不足。** 台风路径具有明显的时间依赖性，同时受到周围大气环流等环境因素影响。仅使用当前经纬度、风速和气压等少量特征进行回归，难以充分反映历史运动状态与环境变化的共同作用。已有研究通过融合历史路径与风场、位势高度场等数据改善预测[1]，但多源数据的有效融合和模型复杂度控制仍是值得研究的问题[2]。所提供论文也指出，模型在转向、快速加速或减速时存在偏差和预测滞后，说明复杂运动过程仍需进一步建模。

**（2）预测目标与路径预测任务之间的衔接不够明确。** 所提供论文的 SVR 部分将移动速度作为输出。移动速度只能表示运动快慢，不能单独确定未来台风中心的位置，还需要移动方向及位置更新方法。论文随后给出了路径预测图，但不同模型如何形成统一的未来位置预测流程，尚需进一步明确。因此，应直接建立历史状态与未来二维位置或位移之间的映射，便于训练、比较和复现。

**（3）泛化能力与预测时效的验证仍不充分。** 论文给出了训练集与测试集的比例，但未充分说明是否按完整台风事件及年份划分。同一台风相邻记录高度相关，若分别进入训练集和测试集，可能使测试结果偏乐观。此外，DTW允许不同时刻的路径点进行对齐，可以反映轨迹形状相似性，却可能弱化到达时间偏差。论文报告的RMSE和DTW数值也缺少清晰的单位及对应预测时长说明，因此需要补充按预测时效计算的同一时刻位置误差。NHC采用预测位置与验证时刻最佳路径位置之间的大圆距离评价路径误差[3]。

**（4）登陆后降水模型的观测依据及空间表达存在局限。** 所提供论文的降水实验及Q3.m代码使用幂律、指数衰减关系生成数据，再添加随机噪声进行拟合。这种实验可以验证拟合流程，却不能证明模型对真实台风降水的预测能力。同时，仅根据风速或距台风中心的距离描述降水，难以充分反映降水的空间不对称性。已有观测及数值研究表明，环境垂直风切变会影响台风内核降水的不对称分布[4]，因此相关模型需要真实降水资料和更多环境特征支持。

## 4. 解决方案的关键思路

本研究拟采用“历史序列建模、环境特征融合、直接预测未来位移、独立事件验证”的技术路线，以台风路径预测为主要任务，并开展分类分析和登陆后降水建模扩展。

**（1）构建时间一致、避免未来信息泄漏的样本。** 利用现有1945—2023年历史台风路径数据，按台风编号和观测时间整理经纬度、风速、气压等变量，统一时间间隔及单位，检查缺失值和异常值。由当前及此前的位置计算历史位移、移动速度和方向变化，以过去24小时的状态序列作为输入，预测未来6、12、24小时的位移。样本构造不得跨越不同台风或较长观测缺口；输入特征及缺失值处理只能使用预测起点及之前的信息。标准化参数仅由训练集估计。

**（2）建立基线模型与时序预测模型。** 首先建立保持当前速度和方向的外推模型，以及预测二维位移的SVR模型，作为比较基线；再使用LSTM提取历史运动和强度变化的时序特征，研究加入注意力机制后能否改善转向及速度突变时的预测。模型直接输出各预测时效对应的二维位移，并还原为未来经纬度，避免只预测速度而不能确定路径的问题。注意力机制的实际贡献通过消融实验检验。

**（3）补充环境数据，研究时空特征融合。** 在获取环境资料后，将路径记录与ERA5等数据按时间和位置匹配，优先考虑多层风场和位势高度等变量，以台风当前中心为基准裁剪环境区域。利用CNN提取网格环境特征，与LSTM提取的历史序列特征融合，比较加入环境信息前后的预测误差。[1][5] 如果仅使用现有路径表，则先完成序列模型；只有补齐网格环境数据后，才开展CNN空间特征实验。ERA5用于历史回报实验，不能把未来时刻的再分析场当作预测时已知输入。

**（4）开展分类分析及真实降水建模扩展。** 利用季节、强度、移动速度、气压和生命周期特征进行统计分析或聚类，考察不同台风类别的预测误差；不直接将聚类结果等同于业务台风强度等级。降水部分在取得真实站点或格点资料后，结合距台风中心距离、方位角、湿度、风切变、地形和登陆后经过时间，比较简单衰减模型与随机森林等多变量模型。明确区分中心最大风速、当地风速、时段降水量和累计降水量，避免混用预测目标及单位。

**（5）通过独立测试和消融实验检验方案。** 按年份和完整台风事件划分训练集、验证集与测试集，确保同一台风不跨集合；模型选择仅使用验证集。分别统计6、12、24小时的位置大圆距离误差，以DTW辅助评价路径形状，并单独分析转向、登陆及快速移动样本。通过移除历史序列、环境特征或注意力模块，判断各部分的贡献。补齐并核验2024年贝碧嘉的真实资料后，将其作为独立案例，最终判断方案是否优于基线，而不预先宣称性能提升。

## 可以具体引用的前人工作

以下将外部文献的研究范围与本地实验的不足分开。前文关于合成降水数据、预测目标衔接和数据划分说明不足的判断，针对本目录实验材料，不能直接套用到这些外部论文。

1. **Gao等（2018）：基于LSTM的台风路径临近预报。[6]** 使用1949—2011年台风观测训练LSTM，开展6—24小时路径预测。它可以作为历史序列建模的直接参考。借鉴其时序预测框架后，本课题可继续研究环境场融合；不能说这项工作没有考虑时间依赖。

2. **Giffard-Roisin等（2020）：历史路径与再分析环境场融合。[1]** 将历史位移和以台风中心为基准裁剪的风场、位势高度场输入融合网络，预测24小时位移。作者明确将其定位为概念验证，并指出当前和过去的再分析场依赖；更长预测时效、环境资料变化和业务预报输入适配仍有研究空间。它已经采用多源融合，不能把“首次融合环境数据”写成本课题创新。

3. **Liu、Hao、Geng和Shi（2022）：DBF-Net多时效路径预测。[2]** 使用LSTM编码解码分支提取台风自身的时序特征，使用CNN分支处理位势高度场，再融合预测6、12、18、24小时路径。预印本表4报告24小时平均距离误差119.05 km；该数值只适用于其数据和实验设置。作者指出与SHTP区域数值模型仍有精度差距，采用更高分辨率环境资料可能进一步改善表现。该工作已经开展消融实验，不能将其描述为“缺少消融验证”。

4. **Chen等（2019）：CNN-LSTM用于台风生成和强度预测。[7]** 采用二维、三维CNN提取大气和海洋变量的空间特征，使用LSTM学习时间关系。它在原论文参考文献中出现，是CNN-LSTM结构的相关应用依据，但其研究目标为生成与强度，不能直接用其结论证明路径预测有效。

5. **He等（2023卷期，2022年12月在线发表）：双注意力多通道ConvLSTM短期风速预测。[8]** 使用华北部分地区ERA5近地面网格资料，通过通道及空间注意力进行6小时风速预测。它也在原论文参考文献中出现，可作为注意力机制的借鉴依据；其区域风速预测结论不能直接外推到台风路径或台风中心风速。

6. **Ueno（2007）：风切变与台风降水不对称性。[4]** 结合西北太平洋台风的雷达、卫星降水资料及数值试验，研究垂直风切变与降水空间分布的关系。它为在降水模型中增加方位角、风切变和强度特征提供物理依据，不能将其称为机器学习降水预测模型。

可用于第3题的文献综述段落：

> Gao等利用LSTM开展6—24小时台风路径预报，说明历史序列中的时间依赖具有预测价值；Giffard-Roisin等进一步将历史位移与以台风中心对齐的风场、位势高度场融合，开展24小时路径预测，但其研究仍以再分析资料上的概念验证为主；Liu等提出DBF-Net，实现多时效时空融合预测，作者同时指出其与区域数值预报模型仍存在精度差距。因此，已有研究已具备时序建模和多源融合能力，后续仍需关注环境资料分辨率及可获得性、较长预测时效和困难台风样本的表现。若扩展降水任务，还需依据降水不对称性的观测研究，引入方位角、风切变等变量，并使用真实降水资料验证。
